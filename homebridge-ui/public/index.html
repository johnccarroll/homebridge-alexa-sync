Alexa account sign-in

Authenticates this plugin against your Amazon account so it can read and control any device linked to your Alexa (Smart Life, Sengled, Hue, etc.). One-time per account; the cookie auto-refreshes every 4 days.

How it works

Clicking Sign in with Amazon spins up a temporary proxy on this Homebridge host. A new browser tab opens to the real Amazon login page (proxied so the cookie is captured on return). Complete the login — including any 2FA prompt — and this page will say Signed in once done. The proxy shuts down automatically.

Use an authenticator-app 2FA code. SMS-based 2FA does not work with Amazon's current proxy flow.
